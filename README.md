# Tror

Быстрый и компактный редактор кода на Rust в духе Notepad++: один исполняемый файл (около 20 МБ), без рантаймов и WebView.

Стек: `eframe/egui` (GPU-рендер), `egui_stack` (стыковка панелей), `ropey` (текст), `syntect` + `two-face` (подсветка по грамматикам Sublime Text), `encoding_rs` + `chardetng` (кодировки), `regex` (поиск), `similar` (сравнение), `ssh2` (SFTP и SSH), `vt100` (эмуляция терминала), `suppaftp` (FTP), `mysql` (MySQL/MariaDB), `rfd` (системные диалоги).

## Что уже есть

- Собственный виджет редактора на rope-структуре (`ropey`): рисуются только видимые строки, поэтому файл в 64 МБ / 400 тыс. строк и минифицированный JSON в 78 МБ одной строкой листаются и правятся так же, как маленькие.
- Вкладки: открытие нескольких файлов, перетаскивание файлов в окно, закрытие средней кнопкой, индикатор несохранённых изменений, запрос при закрытии.
- Свободная компоновка: редактор, удалённые хосты, SSH-консоль, журнал, поиск на сервере, база данных, сравнение и настройки — отдельные панели. Любую можно перетащить за заголовок: к краю окна или другой панели (прилипнет и разделит место), на чужой заголовок (станет соседней вкладкой) или открепить в плавающее окно через правый щелчок по заголовку. Файлы тоже: два документа рядом — перетащите вкладку к краю. Расположение запоминается; «Вид → Сбросить расположение панелей» возвращает исходное.
- Подсветка синтаксиса для ~200 языков: PHP (вместе с HTML/JS/CSS внутри), HTML, JavaScript/TypeScript, Twig, CSS/SCSS/Less, Python, Rust, SQL, JSON, YAML, TOML, Markdown и др. Язык определяется по расширению и первой строке, меняется в строке состояния. Файлы `.log` и `.txt` открываются без подсветки (её можно включить вручную в строке состояния).
- Подсветка инкрементальная и ограничена 8 мс на кадр. Файлы до 2 МБ раскрашиваются целиком и точно; в больших раскрашивается только окно вокруг видимой области.
- Кодировки: UTF-8 (с BOM и без), UTF-16, Windows-1251, KOI8-R, CP866, Windows-1250/1252. Автоопределение, смена кодировки сохранения, «Переоткрыть как». Переводы строк LF/CRLF/CR сохраняются как в исходном файле.
- Поиск и замена: регистр, слово целиком, регулярные выражения с группами (`$1`, `${name}`), подсветка совпадений, счётчик, «Заменить все». В больших файлах поиск идёт в фоновом потоке.
- Отмена/повтор на снимках rope (общая память между снимками), выделение мышью и клавиатурой, двойной/тройной щелчок, отступ блока Tab / Shift+Tab, автоотступ, переход к строке.
- Подсказки при наборе (от двух символов) и по Ctrl+Пробел: слова из документа рядом с курсором плюс словари PHP, HTML, Twig, JavaScript, jQuery, CSS, Python, Rust. Набор словарей зависит от контекста: после `<` — теги, после `.` в JS — методы и jQuery, с `$` в PHP — переменные.
- Удалённые хосты по SFTP и FTP (F8): профили подключений, панель с каталогом сервера, открытие файла двойным щелчком, Ctrl+S загружает правки обратно.
- В панели: выделение нескольких объектов (Ctrl и Shift), перемещение перетаскиванием на папку, создание, переименование, удаление папок вместе с содержимым, загрузка файлов с компьютера (через меню или перетаскиванием в окно), скачивание одного файла или нескольких в папку, колонки размера и даты изменения, кнопка обновления каталога.
- Соединение держится само: раз в 25 секунд идёт проверка, при обрыве программа подключается заново и повторяет операцию. Если сохранить удалённый файл после отключения, программа сама подключится к его серверу и загрузит изменения.
- Поиск на сервере (отдельная панель): по тексту файлов или по именам в открытой папке и глубже, со списком папок-исключений (по умолчанию кеш и резервные копии Битрикса, `node_modules`, `.git`). По SFTP поиск выполняют `find` и `grep` на самом сервере; если их нет или это FTP — программа обходит каталоги сама. Двойной щелчок по результату открывает файл на нужной строке.
- Журнал (отдельная панель, «Вид → Журнал»): сырой обмен с сервером, как в окне Output у NppFTP. Для FTP — каждая команда (`-> CWD /www`) и каждый ответ сервера дословно (пароль в `PASS` скрыт); для SSH/SFTP — версия сервера, согласованные алгоритмы, отпечаток ключа, методы входа, операции SFTP и коды ошибок libssh2; для баз — запросы и ошибки сервера. Строки можно выделять, есть «Копировать всё».
- Вкладки помечаются: точка — есть несохранённые изменения, зачёркнутое название — файла больше нет на сервере или диске (при переходе на такую вкладку программа спросит, оставить её или закрыть).
- SFTP: вход по паролю, по файлу ключа (с парольной фразой) или через ssh-agent; ключ сервера проверяется — при первом подключении показывается отпечаток, при его смене выводится предупреждение.
- SSH-консоль (F9): терминал xterm-256color с цветами, полноэкранными программами (less, vim, mc, top), прокруткой истории колесом и вставкой из буфера. Подключается по выбранному SFTP-профилю.
- Перенос строк (Alt+Z): по словам, без горизонтальной прокрутки; работает и на огромных файлах.
- Настройки (Ctrl+,) — отдельная вкладка. Тёмная и светлая темы, для каждой свой набор: 15 цветов интерфейса (фоны, кнопки, границы, текст, акцент, выделение, текущая строка, совпадения поиска) и цвета подсветки кода (схема из 30+ готовых плюс свои цвета для комментариев, строк, чисел, ключевых слов, функций, тегов, атрибутов, переменных). Цвет выбирается в палитре или вводится как `#rrggbb`, `#rgb`, `rgb(r, g, b)`. Шрифт интерфейса и шрифт кода — любой файл TTF/OTF; размеры текста, межстрочный интервал, масштаб окна, скругление углов. Оформление целиком экспортируется в файл и импортируется из него. Inter и JetBrains Mono встроены.
- База данных MySQL / MariaDB («Инструменты → База данных»): профили подключений, дерево баз и таблиц, просмотр таблицы щелчком, структура, индексы и SQL создания через правый щелчок, выполнение запросов (Ctrl+Enter; выделенный фрагмент выполняется отдельно), таблица результата с виртуальной прокруткой, копирование ячейки и строки, экспорт в CSV. К базе на хостинге можно ходить через SSH-туннель по уже настроенному SFTP-профилю.
- Сравнение файлов («Инструменты → Сравнить с другим файлом»): два открытых документа рядом, построчно, с переходом по изменениям; двойной щелчок по строке открывает её в редакторе. Пересчитывается при правках.
- Предпросмотр в браузере (F12): для локальных файлов программа поднимает сервер на `127.0.0.1` в папке файла и открывает страницу в системном браузере; после каждого сохранения страница перезагружается сама. Для `.php` запускается `php -S` (нужен установленный PHP). Для файлов с сервера открывается адрес сайта из профиля хоста.
- Восстановление сессии.

## Замеры

Linux, 2 ядра, программный рендер (без видеокарты), release-сборка:

| Операция | Результат |
| --- | --- |
| Открытие SQL-дампа 64 МБ (403 тыс. строк) | 175 мс |
| Время кадра при наборе, прокрутке, поиске в нём | в среднем 0,2–2 мс, худший ~10–13 мс |
| «Заменить все», 403 тыс. замен в 64 МБ | ~0,2 с |
| Сохранение 64 МБ | ~0,15 с |
| Память процесса с этим файлом | ~197 МБ, после «Заменить все» ~278 МБ |

Свой замер: `TROR_PERF=1 tror файл` печатает в stderr время открытия и статистику кадров раз в секунду.

## Установка

Готовые сборки лежат в артефактах прогонов: https://github.com/Jozef2J/tror/actions (нужен вход в GitHub).

- **Windows:** `tror-windows-x86_64` — внутри `tror.exe`, установка не нужна. SmartScreen при первом запуске: «Подробнее» → «Выполнить в любом случае».
- **macOS:** `tror-macos-universal` — внутри `Tror-macos.zip`, в нём `Tror.app` для Intel и Apple Silicon. Распакуйте и перетащите `Tror.app` в «Программы». Приложение не подписано сертификатом Apple, поэтому первый запуск такой: щёлкнуть правой кнопкой → «Открыть» → «Открыть»; в новых версиях macOS — «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». То же одной командой: `xattr -dr com.apple.quarantine /Applications/Tror.app`.
- **Linux:** `tror-linux-x86_64` — внутри `tror-linux-x86_64.tar.gz`: `tar -xzf tror-linux-x86_64.tar.gz && ./tror`.

## Сборка

Нужен Rust 1.95+ и компилятор C (MSVC Build Tools на Windows, Xcode CLT на macOS, gcc/clang на Linux) — он требуется для Oniguruma и libssh2. На Linux и macOS дополнительно нужны `perl` и `make`: OpenSSL собирается из исходников и вшивается в программу (первая сборка дольше на несколько минут).

```
cargo run --release
cargo run --release -- путь/к/файлу.php другой.js
cargo test
```

Готовый файл: `target/release/tror` (`tror.exe` на Windows). В `.github/workflows/build.yml` — сборка под Windows, Linux и macOS.

## Профили подключений

Профили лежат в файле `connections.json` в каталоге данных программы (путь показан в окне «Профили»): `%APPDATA%\Tror\data` на Windows, `~/.local/share/tror` на Linux, `~/Library/Application Support/Tror` на macOS. Файл можно переносить между машинами. Пароли в нём скрыты от случайного взгляда (XOR + hex), но не зашифрованы — любой, у кого есть файл, может их восстановить. Там же хранятся отпечатки ключей серверов и подключения к базам данных (их пароли скрыты тем же способом).

## Известные ограничения

- FTPS (FTP поверх TLS) не поддерживается — только обычный FTP, который передаёт пароль открытым текстом.
- В SSH-консоли нет выделения и копирования текста мышью, жирный шрифт и подчёркивание не отображаются; Ctrl+C, Ctrl+X и остальные сочетания с Ctrl уходят на сервер, пока консоль в фокусе. Консоль одна.
- База данных: только MySQL/MariaDB, соединение без TLS (для удалённых серверов — через SSH-туннель), вход по паролю (`mysql_native_password`, `caching_sha2_password`). В результате показываются первые 5000 строк, длинные значения обрезаются до 4000 символов; правки данных — только запросами. На настоящем сервере MySQL ещё не проверялось — тесты шли на имитации протокола.
- Предпросмотр открывается во внешнем браузере, встроенного окна страницы нет. Локальный сервер отдаёт папку файла любому процессу на этом компьютере, пока программа запущена.
- Сравнение: файлы до 32 МБ, без подсветки отличий внутри строки и без переноса правок между сторонами.
- Плавающие панели живут внутри главного окна, вынести их на другой монитор нельзя.
- Одно окно и одно подключение к файлам. Файл передаётся целиком без индикатора процента. Перетащить файл из панели в проводник нельзя — скачивание через контекстное меню. С компьютера загружаются файлы, но не папки.
- Вкладки с удалёнными файлами не восстанавливаются при следующем запуске.
- В режиме переноса строки длиннее 5000 символов режутся по ширине окна без учёта границ слов и не подсвечиваются; обход каталогов при поиске по FTP медленный — каждый файл скачивается целиком.
- В файлах больше 2 МБ подсветка приблизительная: разбор начинается за 200 строк до видимой области, поэтому внутри длинного многострочного комментария или строки цвета могут быть неверными. Строки длиннее 10 000 байт не подсвечиваются.
- Файл целиком держится в памяти; открытие, сохранение и «Заменить все» выполняются в потоке интерфейса.
- В строках длиннее 5000 символов позиция по горизонтали считается по сетке моноширинного шрифта; табуляции и широкие символы (CJK, эмодзи) в таких строках сдвигают курсор.
- Подсказки — это имена без сигнатур и описаний; слова документа берутся из 2500 строк вокруг курсора.
- Мультикурсора, сворачивания блоков и меню «Правка» нет.
- Новые панели (стыковка, база, сравнение, предпросмотр) проверены на Linux; на Windows и macOS — только сборка в CI.

## План

1. Несколько окон и подключений, перенос между серверами, скачивание перетаскиванием, FTPS, индикатор передачи.
2. Настройка горячих клавиш, PostgreSQL и SQLite, правка данных в таблице, отличия внутри строки в сравнении.
3. Плагины, сигнатуры функций в подсказках, пользовательские словари, мультикурсор.
