# Tror

[English](README.md) · **Русский**

Tror — набор инструментов для тех, кто делает и сопровождает сайты. Первое приложение проекта — **TrorPad**: быстрый и компактный редактор кода на Rust. Один исполняемый файл, огромные файлы без торможения, а рядом — всё, что нужно для работы с сайтом на сервере.

- **Редактор:** файлы 50 МБ и больше, подсветка ~200 языков, подсказки, поиск и замена с регулярными выражениями — в файле и по всему проекту, именованные макросы, восстановление несохранённого после сбоя, сравнение файлов, сворачивание блоков, закладки.
- **Визуальный редактор HTML:** страницы HTML, PHP и Twig правятся как оформленный текст — заголовки, списки, ссылки, таблицы, картинки. Вставки PHP и Twig не трогаются. При вставке из Word и Google Docs сохраняется структура, а цвета и шрифты сбрасываются; можно импортировать `.docx`.
- **Серверы:** SFTP, FTP и FTPS с профилями, несколько подключений и передача между ними, перетаскивание между сервером, проектом и рабочим столом, окно скачивания с ходом, паузой и отменой, поиск на сервере, синхронизация папки, архивы, журнал с сырым обменом.
- **Надёжное сохранение на сервер:** перед записью TrorPad проверяет, не изменился ли файл на сервере после открытия, и предлагает сравнить или перезаписать. Прежняя версия с сервера сохраняется в локальные резервные копии.
- **Консоль:** сеансы SSH, Telnet и Mosh во вкладках, свои цветовые схемы и шрифты. Ключи OpenSSH и PuTTY (`.ppk`).
- **Базы данных:** MySQL/MariaDB, PostgreSQL и SQLite, в том числе через SSH-туннель и по TLS; история запросов; экспорт в CSV, JSON и SQL.
- **Интерфейс:** любую панель можно перетащить, пристыковать к краю, открепить или вынести в отдельное окно; цвета, шрифты и горячие клавиши настраиваются. Интерфейс на русском и английском.
- **Плагины:** плагины WebAssembly с явными разрешениями и SDK на Rust (см. [`sdk/`](sdk/)).

## Установка

Готовые файлы — на странице выпусков: https://github.com/Jozef2J/tror/releases/latest

- **Windows:** `trorpad-setup.exe` — установщик (ярлык, пункт «Открыть в TrorPad» в меню файлов), либо `trorpad.exe` — без установки. Файлы пока не подписаны сертификатом, поэтому SmartScreen спросит: «Подробнее» → «Выполнить в любом случае».
- **macOS:** `TrorPad-macos.zip` → `TrorPad.app` в «Программы». Первый запуск: правый щелчок → «Открыть», либо `xattr -dr com.apple.quarantine /Applications/TrorPad.app`.
- **Linux:** `chmod +x trorpad-linux-x86_64 && ./trorpad-linux-x86_64`.

Программа сама сообщает о новой версии и ставит её по кнопке (Windows и Linux; на macOS откроет страницу выпуска). Проверку можно выключить в настройках.

## Скорость

Каждая сборка в CI запускает `trorpad --bench` и публикует цифры в сводке прогона. Если операция стала медленнее своего предела, сборка падает.

Версия 0.14.0, Linux, 2 ядра, программный рендер без видеокарты, release-сборка, файл уже в кеше диска:

| Что | Результат |
| --- | --- |
| Запуск до первого кадра | 57–74 мс |
| Открытие SQL-дампа 64 МБ (403 тыс. строк) | 133–180 мс |
| Открытие JSON 78 МБ одной строкой | 142 мс |
| Кадр при наборе, прокрутке и отмене в дампе 64 МБ | в среднем 1,7–2,1 мс, худший 15–19 мс |
| «Заменить все», 403 тыс. замен в 64 МБ | 0,34 с |
| Сохранение 64 МБ | 0,1 с |

Свой замер: `TROR_PERF=1 trorpad файл` печатает время открытия, время до первого кадра и статистику кадров раз в секунду.

## Сборка

Нужен Rust 1.95+ и компилятор C; на Linux и macOS ещё `perl` и `make` (OpenSSL собирается из исходников).

```
cargo run --release -- путь/к/файлу.php
cargo test
```

## Важно знать

- Пароли профилей хранятся в системном хранилище (Диспетчер учётных данных Windows, Связка ключей macOS, Secret Service в Linux). В переносном режиме их можно держать в `connections.json` — там они замаскированы, но не зашифрованы.
- Файл целиком держится в памяти; в файлах больше 2 МБ подсветка приблизительная.
- Плагины получают только те разрешения, которые вы им дали. Пароли плагинам не передаются никогда.
- TrorPad не собирает телеметрию. См. [политику конфиденциальности](PRIVACY.md#русский).
